POST /api/ask · worker/rag.ts

Ask workflow

Each question is a fresh retrieve-and-answer. The chat does not send history. Gemini speaks as AJ in first person.

  1. 01

    Browser

    AskChat on / opens on focus or submit. Sample prompts, hero, and composer POST JSON { question } to /api/ask. Clear bumps a turn id so an in-flight reply is dropped.

  2. 02

    HTTP

    Worker intercepts /api/ask before vinext. parseQuestion requires a non-empty string, max 500 characters. GET returns status only. Success body is { answer, retrieval }.

  3. 03

    Gemini-first

    If GEMINI_API_KEY is bound, Flash-Lite sees the AJ persona, live facts brief, and tech lists. Greetings and tenure questions can stop here as retrieval: gemini. Project write-ups, product detail, or “how this chat works” return NEED_SITE_CONTEXT. No key skips this pass.

Usable Gemini reply

Return { answer, retrieval: gemini, sources: [] }. RAG does not run. UI hides the cosine disclaimer.

Need site context

Empty reply, NEED_SITE_CONTEXT, “not on this site yet”, thrown error, or missing key → retrieve.

  1. 04

    Ingest

    Once per isolate per calendar month, embed every corpus chunk with gemini-embedding-001 (768-d, L2-normalized) and upsert into Vectorize portfolio-rag. Metadata is title, url, source. Passage text is always read from corpus.ts.

  2. 05

    Retrieve

    Lexical search always runs on the live corpus (topK 5). Vector search embeds the question as RETRIEVAL_QUERY and takes cosine topK 5. Merge vector-first, cap at 8. Any vector hit labels retrieval: vectorize; otherwise lexical.

  3. 06

    Ground

    Force-include named tech chunks plus summary, profile, contact, or facts when those detectors fire. Drop tech-undated when a dated tech is named. Drop site-rag unless the visitor asked how the chat works.

  4. 07

    Generate

    directAnswer first: name, lookupTechAnswer, think() from live spans. Else Gemini answers from facts + numbered chunks. Else extractive: top chunk, or a first-person “not on this site yet”.

  5. 08

    Reply in the dialog

    Assistant message with retrieval. Cosine disclaimer shows unless retrieval is gemini. Failure copy points at toolkit, work, and email.
